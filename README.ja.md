# Side View

**投稿は読む。タイムラインはそのまま。**

![Side View は X で投稿をタイムラインの横に開きます](assets/store/screenshots/01-x-sidebar.jpg)

こういう体験、あるはずです。タイムラインの中ほどまで読んでいたとき、目を引いた投稿をクリック
した瞬間、フィードごと消えてしまう。元の場所へ戻るために長いスクロールをやり直すはめになり、
1 分前に読んでいた内容はもう手の届かないところに行ってしまう。

Side View はその投稿を**タイムラインの横のカラムに開きます**。フィードはもとの場所にじっ
と残ります。読み終えて、返信して、スレッドを最後までスクロールして、閉じても、まだ同じ画面
です。

**X**、**Bluesky**、**Threads** に対応しています。

---

## 実際にできること

フィード内の投稿をクリックすると、ページ全体を置き換えるのではなく、そばに開きます。もう
1 つクリックすれば、同じ場所にそのまま。閉じてもタイムラインは無傷です。そもそも、どこにも移動
していないからです。

それだけです。新しいアプリは要らず、登録も要らず、別のサイトにも行きません。いつものアカウント
でログインしたままで、投稿はサイト本来の表示のままです。スレッド、画像、動画、投票、返信も、
すべてそのままです。

- **何を開くかは選べます。** プロフィール・ハッシュタグ・検索を対象から外して、投稿だけをこの
  方式で開くこともできます。
- **幅も選べます。** 320 から 1200 ピクセルまで、ウィンドウに合わせて調整できます。
- **ナビゲーションの占有幅も選べます。** アイコンだけの細いレールに縮めることもできますし、
  そのままにしておくこともできます。
- **4 言語対応。** English、简体中文、繁體中文、日本語、またはブラウザーの設定に従います。

## 各プラットフォームでの動作

**X と Bluesky では、** カラムを Side View 自身が描画し、フィードの隣に配置します。右側のサイ
ドバーを置き換えるように、サイドバーの横に両方を並べておくこともできます。

**Threads のホームでは、** 置き換えるサイドバーがないため、Threads 自身のカラム機能を使います。
Threads のアカウントに保存される 1 本のネイティブカラムで、投稿を開くたびに同じカラムを使い
回します。移動も、幅の調整も、スクロールも、いつもの習慣どおりにできます。
アクティビティ、フォロー中、保存済み、いいね、おすすめ、アーカイブ、カスタムフィード、検索の
単独ページでは、一時的なネイティブカラムを開きます。URL は変わらず、アカウントにも保存しません。
カラムメニューから閉じられます。640 CSS ピクセルのカラム 2 本とナビゲーションが収まる幅が必要です。表示領域やネイティブ機能が
利用できない場合は、通常のページ遷移を維持します。

![Bluesky でも、投稿はフィードの横に開きます](assets/store/screenshots/02-bluesky-sidebar.jpg)

![Threads では、Threads 自身のカラムに投稿が開きます](assets/store/screenshots/03-threads-native-column.jpg)

## はじめかた

1. Chrome ウェブストアから Side View をインストールします。ストアのリンクは公開後、ここに追加
   されます。
2. X、Bluesky、Threads を普段どおり開くだけです。それ以上の設定はありません。
3. 投稿をクリックします。タイムラインの横に開きます。

単独で表示したい場合は、各詳細パネルの「新しいタブで開く」ボタンを使えます。

## 設定

ブラウザーの拡張機能メニューから設定ページを開きます。専用のタブで開くので邪魔をせず、変更は
その場で保存されます。

![Side View の設定ページ](assets/store/screenshots/04-settings.png)

## プライバシー

Side View にサーバーはなく、アカウントもなく、アクセス解析もありません。すでに見ているページ
から、クリックした投稿を読み取ってカラムに表示するだけで、それきりは扱いません。設定はブラウ
ザーに保存されます。収集されることも、売ることも、誰かに送ることもありません。

一点だけ重申します。Threads のカラムは Threads 自身が作成し、あなたの Threads アカウントに
保存されます。これは Threads の仕様であり、当方の動作ではありません。Side View を無効にしても、
拡張機能を削除しても、このカラムは消えません。削除するには Threads 自身のカラムメニューから
2 クリックで操作できます。詳細は[プライバシーポリシー](docs/privacy-policy.md)に記載しています。

## 補足

- **Side View は独立した拡張機能です。** X、Bluesky、Meta とは提携・承認・後援の関係にありませ
  ん。
- **サイトは変わります。** Side View は各サイト自身のレイアウトに接続しています。そのため、
  サイト側がデザインを変更すると、更新をまたいで機能が一時的に動かなくなることがあります。
  そのときは [お知らせください](docs/support.md)。
- **アカウント登録は不要です。** 登録するものも、支払うものもありません。Side View は、入れる
  だけで使えるブラウザ拡張機能です。
- **タイムラインは変更されません。** Side View が並び替え、隠したり、書き換えたりすることはあり
  ません。閉じれば、ページは操作前とまったく同じです。

## ご自分でビルドする

Side View はオープンソースです。Node 22+ と pnpm 10 が必要です。

```bash
git clone https://github.com/YoungSx/side-view.git
cd side-view
pnpm install
pnpm dev      # ホットリロード付きの開発ビルド
pnpm build    # 本番ビルド → .output/chrome-mv3
pnpm test     # テストを実行
```

`chrome://extensions` で `.output/chrome-mv3` を「展開済みの拡張機能」として読み込みます。
アーキテクチャの説明、多言語化のガイド、実機検証チェックリストは
[docs/development.md](docs/development.md) にあります。
